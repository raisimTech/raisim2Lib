# Web tools

Explore physics or build a scene directly in your browser. RaiSim handles the simulation and Rayrai renders the world. Choose a tool to get started.

<WebTools />

Both tools run locally, with no installation or account required. Your scenes stay in your browser. The scene editor can export a `.rscene` file for RaiSim Engine 2 or a desktop RaiSim application.
