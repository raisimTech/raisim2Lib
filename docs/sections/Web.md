# Web tools

Explore physics, build a scene or play a game directly in your browser. RaiSim handles the simulation and Rayrai renders the world. Choose a tool to get started.

<WebTools />

They run locally, with no installation or account required. Your scenes stay in your browser. The scene editor can export a `.rscene` file for RaiSim Engine 2 or a desktop RaiSim application.

To build browser programs of your own on RaiSim and Rayrai, use the [WebAssembly SDK](./WebAssemblySdk.md).
