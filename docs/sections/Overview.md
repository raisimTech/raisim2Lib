# Documentation overview

RaiSim is a cross-platform multi-body physics engine for robotics and AI. The
binary package provides rigid bodies, articulated systems, deformable bodies,
granular particles, rayrai RGB/depth sensor rendering, deterministic CPU ray
sensors for headless use, `RaisimServer` streaming, and the rayrai OpenGL
visualizer.

If you are new to RaiSim, start with the page that matches your goal:

| Goal | Start here |
| --- | --- |
| Install and run one example | [Quick Start](./QuickStart.md) |
| Find the right example target | [Examples](./Examples.md) |
| Visualize a running `RaisimServer` scene | [Visualization](./Visualization.md), [Raisim Server](./RaisimServer.md), and [rayrai Visualizer](./Rayrai.md) |
| Add objects, contacts, sensors, or materials | [World](./WorldSystem.md), [Objects](./Object.md), [Contact and Collision](./Contact.md), [Sensors](./Sensors.md), and [Material System](./MaterialSystem.md) |
| Build examples, run timing examples, or tune a binary package scene | [Build, Test, and Benchmark](./BuildAndTest.md), [Project Layout](./ProjectLayout.md), and [Performance](./Performance.md) |
